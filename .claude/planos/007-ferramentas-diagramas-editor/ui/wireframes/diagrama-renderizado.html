Guia de Uso

Visão geral da autenticação e dos principais fluxos do sistema.

Fluxo de Login

O processo de autenticação segue o padrão JWT com refresh token de 30 dias.

100%

Após a autenticação, o token deve ser enviado no header Authorization: Bearer <token> em todas as requisições subsequentes.

Renovação de Token

O refresh token expira em 30 dias. O fluxo de renovação é automático via interceptor no Frontend.
